Tutoriais
=========

Aqui estão alguns tutoriais úteis para você começar a usar o Podman.
Se você já conhece a `engine de contêiner`_ do Docker, os comandos do Podman
devem ser bem familiares.
Se você é iniciante em contêineres, dê uma olhada na nossa `Introdução`.

* `Configuração básica e uso do Podman <https://github.com/containers/podman/blob/main/docs/tutorials/podman_tutorial.md>`:
  Aprenda como configurar o Podman e executar alguns comandos básicos com o
  utilitário.
* `Configuração básica e uso do Podman em um ambiente sem root <https://github.com/containers/podman/blob/main/docs/tutorials/rootless_tutorial.md>`:
  Os passos necessários para configurar o Podman sem root são descritos.
* `Podman para Windows <https://github.com/containers/podman/blob/main/docs/tutorials/podman-for-windows.md>`:
  Um guia para instalar e usar o Podman no Windows.
* `Clientes remotos do Podman no Mac/Windows <https://github.com/containers/podman/blob/main/docs/tutorials/mac_win_client.md>`:
  Configuração avançada para conectar-se a um sistema Linux remoto usando o
  cliente remoto do Podman no Mac e no Windows.
* `Como assinar e distribuir imagens de contêiner usando o Podman <https://github.com/containers/podman/blob/main/docs/tutorials/image_signing.md>`:
  Aprenda como configurar e usar a assinatura de imagens com o Podman.
* `Tutorial do remote-client do Podman <https://github.com/containers/podman/blob/main/docs/tutorials/remote_client.md>`:
  Um breve guia sobre como usar o remote-client do Podman.
* `Como usar o libpod para projetos personalizados/derivados <https://github.com/containers/podman/blob/main/docs/tutorials/podman-derivative-api.md>`:
  Como a API do libpod pode ser usada em seu próprio projeto.
* `Como usar as bibliotecas RESTful do Podman para Go <https://github.com/containers/podman/tree/main/pkg/bindings>`:
  Uma introdução ao uso de nossas bibliotecas RESTful para Go em uma aplicação
  externa.
* `Configurações de rede comuns <https://github.com/containers/podman/blob/main/docs/tutorials/basic_networking.md>`:
  Um guia básico para configurações de rede comuns no Podman.
* `Ativação de socket <https://github.com/containers/podman/blob/main/docs/tutorials/socket_activation.md>`:
  Aprenda como executar contêineres que suportam ativação de socket.
